# Security

Report suspected issues privately through the repository owner's GitHub contact options or GitHub private vulnerability reporting when enabled. Do not include tokens, transcripts, vault notes or CRM data in a public issue.

This preview has no support guarantee. Priorities include cross-session answer routing, path confinement, native permission boundaries, unsafe installation recipes and local credential exposure. A local process running as the same user can access that user's private state; the companion is not a sandbox against the OS account owner.
