# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Approved implementation plan: vanilla HTML/CSS/Canvas, Node ESM, local HTTP/MCP and SQLite.

## Users
People building projects with Codex or Claude Code who want a game-like way to communicate with their coding agent.

## Product Purpose
Make agent questions, selected skills, real task activity and project decisions visible as a construction site.

## Operating Context
The user prompts their existing coding host. Superpowers is the head engineer workflow. Skills become crew assignments. Obsidian-compatible notes hold approved project knowledge.

## Capabilities and Constraints
User-controlled skill recommendations and installation review; native execution permissions; correlated questions; explicit offline and unsupported states; local browser dashboard. Compatibility is development status until native acceptance passes.

## Brand Commitments
Owner approved warm paper, dark ink, construction orange and original CC0 pixel workers. The current V1 prototype is archived separately.

## Evidence on Hand
Approved design and implementation plans under docs/superpowers. Working backend fixtures; native host acceptance remains open. No full reference-video transcript.

## Product Principles
Show evidence honestly. Preserve user choice. Keep context bounded. Use the current coding agent. Make recovery understandable.

## Accessibility & Inclusion
Keyboard operation, readable HTML equivalents, reduced motion, 320 px layouts and 200% zoom.
