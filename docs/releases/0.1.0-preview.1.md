# Construction Companion V2 development preview

A local pixel construction site beside your coding agent, with a head engineer question panel, user-controlled skill recommendations and an optional project notebook. V1 remains separately preserved.

**This preview is not yet the complete two-host user-ready release.** Real Codex/Claude questions stay in host chat. Codex registration and MCP discovery passed; bundled hook discovery, ordinary-prompt behavior and native answer delivery remain unverified. Claude Code has not been tested natively. The tutorial visibly uses simulated host events.

## Try it

Install Node.js 22.13 or newer, then use the source checkout:

```sh
git clone https://github.com/JaiReyes45/construction-companion.git
cd construction-companion
npm ci --ignore-scripts
node scripts/demo.mjs --copy-token
```

Open the printed local URL, paste the copied token and choose **Connect**. Ctrl+C stops the demo. The demo makes no model requests. See the [README](../../README.md) for project installation and native limitations.

## Downloads

- `construction-companion-v2-tutorial.mp4`: one-minute captioned browser tutorial with a visible demo label.
- `construction-companion-v2-tutorial.srt`: separate captions.
- `construction-companion-codex-0.1.0-preview.1.zip`: standalone Codex plugin package with pinned runtime dependencies.
- `construction-companion-claude-0.1.0-preview.1.zip`: standalone Claude package for development and acceptance testing; native support unverified.
- `SHA256SUMS.txt`: checksums for the four assets above.

The plugin archives are developer packages, not one-click installers. Source setup is the documented path. Node.js is still required. No npm package or public plugin-directory listing is claimed.
